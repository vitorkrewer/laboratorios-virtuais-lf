[🔗 Acessar Laboratório Online](https://vitor-v-costa.github.io/laboratorios-virtuais-lf/tabela-periodica-interativa/)

---

## 📸 Visão Geral

Este projeto oferece uma ferramenta educacional moderna com duas funcionalidades principais: um construtor de átomos e uma tabela periódica clicável. A interface é limpa, responsiva e conta com animações fluidas para uma melhor experiência do usuário.

---

## ✨ Funcionalidades

* **Construtor de Átomos:** Adicione ou remova prótons e nêutrons para construir diferentes isótopos e ver instantaneamente o elemento correspondente e seu número de massa.
* **Visualização do Núcleo:** Veja o núcleo atômico ser construído em tempo real com partículas animadas.
* **Tabela Periódica Interativa:** Explore todos os 118 elementos em uma tabela responsiva que se adapta a qualquer tamanho de tela.
* **Modal de Detalhes do Elemento:** Clique em um elemento para abrir uma janela com informações detalhadas, como resumo, descobridor e configuração eletrônica.
* **Design Moderno:** Interface limpa com tema claro e escuro (Light/Dark Mode).
* **Totalmente Responsivo:** Funciona perfeitamente em desktops, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído sem frameworks complexos, focando em tecnologias web fundamentais:

* **HTML5:** Estrutura semântica do conteúdo.
* **CSS3:** Estilização, layout responsivo (Flexbox/Grid) e cores das categorias de elementos.
* **JavaScript (ES6+):** Lógica do aplicativo, manipulação do DOM e interatividade.
* **[Tailwind CSS (via CDN)](https://tailwindcss.com/):** Classes utilitárias para agilizar a estilização da interface.
* **[Anime.js (via CDN)](https://animejs.com/):** Biblioteca de animação para dar vida às partículas do núcleo e às transições da interface.

## 🚀 Como Executar Localmente

Nenhuma instalação complexa ou dependências são necessárias. Basta seguir os passos abaixo:

1. **Clone o repositório:**

    ```bash
    git clone https://github.com/vitor-krewer/tabela-periodica-interativa.git
    ```

2. **Navegue até o diretório do projeto:**

    ```bash
    cd tabela-periodica-interativa
    ```

3. **Abra o arquivo `index.html`:**

    Abra o arquivo `index.html` diretamente no seu navegador de preferência (Chrome, Firefox, etc.).

E pronto! O laboratório estará funcionando na sua máquina.
