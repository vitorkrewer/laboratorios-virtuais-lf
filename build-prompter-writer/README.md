# Gerador de Prompt para Material Didático ✒️

O **Gerador de Prompt** é uma ferramenta web interativa projetada para auxiliar professores, conteudistas e designers instrucionais a criarem prompts altamente estruturados e detalhados para Inteligências Artificiais Generativas (como ChatGPT, Claude e Gemini). O foco principal foi a criação de prompts otimizados para o aprendizado de conteúdos acadêmicos utilizando o Google Gemini.

Ao invés de gastar tempo escrevendo prompts do zero, o usuário preenche um formulário guiado e a ferramenta gera automaticamente um comando otimizado, incorporando as melhores práticas pedagógicas e de engenharia de prompt.

## 🚀 Funcionalidades Principais

### 1. Múltiplos Templates Especializados

A ferramenta oferece 4 templates distintos, adaptando o formulário e a estrutura do prompt gerado para cada necessidade:

* **📚 Material Didático Geral:** Versátil para criar apostilas e roteiros de aula. Foca em objetivos de aprendizagem e estrutura curricular.
* **🔖 Fichamento Acadêmico:** Especializado para resumir e analisar textos (livros, artigos, teses). Gera um prompt que instrui a IA a fazer um fichamento crítico e estruturado.
* **🏆 Concursos Públicos:** Focado em materiais preparatórios. Inclui instruções para gerar "bizus", questões comentadas, mapas mentais e focar na aprovação.
* **🎓 Livro Didático (Nível Superior):** O template mais robusto. Foca em rigor acadêmico, citações ABNT estritas, andragogia (ensino para adultos) e uso de fontes primárias.
* **🔬 Artigo Científico:** Focado na redação e estruturação acadêmica para artigos científicos (originais, revisões sistemáticas, estudos de caso e ensaios teoricos), considerando normas de citação (ABNT, APA, IEEE, Vancouver), problema de pesquisa, hipótese e metodologia.

### 2. Interface Dinâmica e Intuitiva

* O formulário muda automaticamente conforme o template escolhido, mostrando apenas os campos relevantes.
* **Preview em Tempo Real:** Veja como seu prompt está ficando enquanto preenche os dados.

### 3. Personalização Pedagógica Completa

Permite definir detalhes cruciais para a qualidade do material gerado pela IA:

* **Público-Alvo e Nível de Instrução:** Define a complexidade do texto.
* **Tom de Voz:** Conversacional, formal, motivacional ou técnico.
* **Recursos Didáticos:** Checkboxes para incluir ou excluir objetivos de capítulo, glossários, quadros de atenção, etc.
* **Andragogia:** Campos específicos para definir como o conteúdo se conecta com a experiência prévia do aluno (no template Superior).

## 🛠️ Tecnologias Utilizadas

* **HTML5 & CSS3**
* **JavaScript (Vanilla JS):** Lógica de processamento de texto e manipulação do DOM.
* **Bootstrap 5:** Framework CSS para responsividade e design moderno.
* **Bootstrap Icons:** Biblioteca de ícones.

## 📦 Como Usar

1. Baixe ou clone este repositório.
2. Navegue até a pasta `build-prompter-writer`.
3. Abra o arquivo `index.html` em seu navegador.
4. Selecione um **Template** no topo da página.
5. Preencha os campos do formulário (Disciplina, Público, Conteúdo, etc.).
6. Clique em **"Copiar Prompt"** e cole na sua IA de preferência.
