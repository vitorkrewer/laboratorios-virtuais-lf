# TextoLab | Fundamentos de PLN

Laboratório híbrido para a disciplina **Fundamentos de Processamento de Linguagem Natural**. A experiência visual local torna observáveis as etapas que normalmente ficam escondidas em uma pipeline de PLN e apresenta o equivalente em Python para continuidade em notebook.

[Acessar laboratório](https://vitorkrewer.github.io/laboratorios-virtuais-lf/nlp-textlab/)

## Módulos iniciais

- **Pipeline:** normalização, tokenização, stop words e lematização sobre um corpus de avaliações em português.
- **Vetores:** comparação de Bag of Words e TF-IDF, vocabulário, n-gramas e esparsidade da matriz documento-termo.
- **Missão:** classificador local Naive Bayes para sentimento, com avaliação e uma área para inferência.
- **Ponte para Python:** código equivalente com `scikit-learn`, atualizado conforme os controles didáticos.

## Formato híbrido

O laboratório não substitui a prática de programação. Cada experimento usa corpus e decisões equivalentes aos que serão implementados em notebooks com `pandas`, `scikit-learn`, `nltk` e `spaCy`. A interface serve para construir intuição antes da implementação e da análise crítica de erros e vieses.

## Execução

O laboratório é estático e local-first. Abra `index.html` em um navegador ou publique a pasta no GitHub Pages. Não há serviços, dados privados ou chaves necessárias.
